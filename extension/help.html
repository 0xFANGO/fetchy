FANGO · 本地视频下载

让浏览器连接你的文件夹。

Fango 通过本机组件解析、下载和校验文件。关闭弹窗后，下载仍在这台电脑上继续。

首次安装 · macOS

  1. 安装 Node.js 22+、Python 3.10+、FFmpeg（包含 ffprobe）。小红书和抖音还需要可用的 Ego Lite 及 ego-browser 命令。
  2. 在项目根目录执行： 
    python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm run extension:build
npm run native:install -- --browser ego

    Chrome 用户将 ego 换成 chrome。移动项目或 Node 路径后，请再次运行安装命令。

  3. 打开浏览器扩展页 chrome://extensions，开启开发者模式，加载项目下的 dist/extension 文件夹，再打开 Fango 点击“重试连接”。

浏览器与登录状态

YouTube / B站使用本地 yt-dlp。小红书 / 抖音通过 Ego Lite 打开目标页面并读取对应视频；不会自动导出你的 Cookie。遇到登录或验证提示，请在实际打开的 Ego Lite 视频页面完成，然后返回插件重试。Chrome 与 Ego Lite 的会话并不共享。

保存位置与恢复

默认保存到系统下载目录中的 Fango 文件夹。可从“设置”选择其他目录并保存；正在下载的任务仍使用启动时的目录。只有视频文件校验通过才显示“已保存”。断开连接时请先重连查询，避免重复下载。

电脑或本地进程重启后不提供断点续传；无法恢复的任务会标为中断。首次支持环境为 macOS；四个平台的可用性取决于具体内容、网络与会话。

项目安装与实测范围详见仓库的 docs/extension-install.md 与 docs/extension-validation.md。
