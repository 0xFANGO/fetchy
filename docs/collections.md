# Reading a visible saved collection

Open the saved list you want in the browser before starting a collection import. Fetchy uses the current page's collection controls and item permalinks. A membership record contains the source site, the item ID and its canonical link. Opening the original and verifying its files are separate steps. [Browser archive](extension-library.md) · [Local library](library.md)

| Site      | Where to start                                                                  | What identifies the collection                                                                                                                                                                                                                                                                                                                         |
| --------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Instagram | Open the profile’s **Saved** directory, **All Posts**, or one named collection. | The directory accepts collection links under the same profile’s saved path. A named collection has a numeric ID. Reading its members also requires a matching collection heading or labeled region. Reel and ordinary post links retain their distinct routes.                                                                                         |
| Douyin    | Open **我 → 收藏**, then choose **视频** or **合集**.                           | Both the active 收藏 control and its subcategory must match. Videos use the signed-in profile’s canonical account ID and the active favorites list. The 合集 directory accepts links with a numeric mix ID. A 收藏夹 tile displaying only a name cannot identify a folder across visits and remains unread. [Douyin help](https://www.douyin.com/help) |
| Threads   | Open **Saved** in the web menu.                                                 | The reader requires a labeled Saved column and the current profile’s navigation link. Each item uses the saved card’s own timestamp link. Quotes and adjacent custom feeds have independent membership. [Threads web controls](https://about.fb.com/news/2025/04/new-features-threads-web-experience/)                                                 |
| TikTok    | On a profile, select **Favorites**, or open a shared named collection.          | The Favorites tab must be active and its member list identifiable. A shared collection uses the numeric ID in its URL and a matching collection region. Videos and photo posts keep their original item IDs.                                                                                                                                           |

A scan without a confirmed total remains partial. When the collection itself reports a total, Fetchy compares it to the number of distinct items. An explicitly empty collection can be confirmed when the page exposes its empty-state message. A blank panel, an unavailable account or a list of recommendations does not establish a collection’s contents.

## Validation

On November 18, 2026, separate Chromium profiles with no prior sign-in opened public entry URLs for these four sites. None exposed a personal saved history that could be checked. No signed-in collection or full-history result is claimed here.

The offline tests exercise the same capture function in Chromium with local pages. They cover account scoping, named folders, post and photo identity, selected tabs, quoted posts, unrelated feeds, total mismatches and empty states. Run `node --test test/collection-page.test.mjs`. The DOM fixtures use a locally installed Chromium browser or the binary selected by `FETCHY_TEST_CHROME`. [Collection tests](../test/collection-page.test.mjs)
