## 自动化验证范围

`npm test` 覆盖原有核心契约与新增行为。新增测试包括：

- 具体目标的封面、无封面兜底、图片地址校验、浏览器公开元数据白名单。
- 手动输入 A→B 竞态、迟到失败响应、慢标签页查询、最新标签页优先、普通页面空状态、跨域 URL 权限丢失后的卡片失效。
- 同一下载启动去重、弹窗重开只恢复原任务、通信断开后的同 ID 查询、启动确认丢失及旧任务返回时解除锁定。
- 完全重启后不保留原始访问输入，不误用其他页面目标重试；同一浏览器会话按任务 ID 恢复内存输入。
- 取消确认、阶段反馈、没有真实总量时不显示百分比、未验证结果不显示成功。
- 系统目录选择结果模拟、选择取消、待保存状态恢复、运行任务固定旧目录。
- Native Messaging 分帧/粘包/长度错误、错误脱敏、真实 host 子进程退出后 daemon 重连。
- 成功输出的文件存在、尺寸/字节数/路径归属校验，以及只允许定位记录中的输出文件。
- 视频标题命名：保留中文/Unicode，清理路径字符、控制字符、嵌入链接和常见凭据片段，限制 UTF-8 文件名长度，缺少可用标题时以内容 ID 等信息兜底；同名追加序号且不覆盖现有文件。
- 文件发布中的并发碰撞、符号链接、取消/清理、磁盘错误，以及浏览器引擎的小红书/抖音模拟下载与 yt-dlp 的真实本地媒体处理均验证最终标题路径。

离线状态测试使用假核心/假系统选择器；真实 host/daemon 测试仍使用受控输入，**不能代替真实平台从扩展发起的下载**。
